evidence of what was built, measured and accepted at each gate. They describe the state at the time
and mention the agents and board cards that did the work; the current behaviour is in the
[feature reference](../FEATURES.md) and the main [docs](../).

  [F4](FREECAD_F4_HANDOFF.md) and the [F5 preparation](FREECAD_F5_PREP.md).
