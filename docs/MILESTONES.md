## M0 — import and prototype enclosure (current)

- Portable board parser and enclosure mesh engine with a C ABI.
- Native iPad file import, parameter controls, orbitable preview, STL share.
- Local project creation and reopening with KiCad 10 starter board/schematic files (implemented; iPad build/device validation pending).
- Touch placement of a two-pin schematic part, wire, label, matching two-pad board footprint and mounting hole, with project-local KiCad libraries (implemented in source; iPad build/device validation pending).
- Direct touch toolbar, pin/endpoint wire snapping, orthogonal preview, overlap rejection, and hold menus for move, rename, and delete (implemented in source; iPad build/device validation pending).
- Optional Open CASCADE STEP export in desktop engine builds.
- Engine test, fixture, Linux CI, and unsigned iPad IPA artifact.

- Imported nets, tracks, vias, pads and footprints can be inspected in the iPad PCB overview.
- Portable single-sheet schematic connectivity, with a tap-to-highlight net view in the app (2026-10-23). In CI, its nets and names match `kicad-cli` 10.0.7 on all 25 single-sheet KiCad demo schematics. It does not cover buses or hierarchy, and it has not been validated on a device.
- Update PCB from schematic, for single-sheet projects (2026-10-23): it sets pad nets and adds missing two-pad footprints. On the touch-authored project, KiCad's audit and `--schematic-parity` DRC report the result consistent. It does not swap footprints or sync automatically.
- Manual F.Cu/B.Cu track and via authoring by touch (2026-10-23). A track takes the net of the pad, track end or via it starts on. On the round-trip board routed in the simulator, KiCad 10.0.6 DRC with schematic parity reports zero violations and zero unconnected items. It has no autorouter and no live clearance checking, and it has not been validated on a device.
- PCB Draw tool (2026-10-26): copper zones on F.Cu or B.Cu with KiCad's default settings, outline replacement with one polygon, and silkscreen and fab lines and text. Hold a zone, line or text to delete it; since 2026-10-29 also to move it (a moved zone is refilled by KiCad in the native edition) or to change a text's string and height. Zones stay unfilled in the default edition; the KiCad edition fills them with KiCad's zone filler. On a board drawn with these calls (`engine/tests/fixtures/drawn`), KiCad's DRC, zone fill and Gerbers matched `kicad-cli` 10.0.6's in Codemagic native-check `6adf53fbb44f189f146b99ac`. There are no cutouts, extra loops, arcs or editing of drawn items, and it has not been validated on a device.
- Library footprints on the board (2026-11-01, KiCad edition): the Part tool places any project or official library footprint, and Swap is KiCad's Change Footprint (reference, pad nets, position, side and orientation kept); Update PCB from Schematic now exchanges changed footprints the same way; kicad-cli reopens the results with the same DRC. Desktop probe and simulator UI tests; not validated on a device.
